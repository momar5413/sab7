# سُبحة 📿

سبحة إلكترونية (عدّاد تسبيح) تعمل على المتصفح وكتطبيق أندرويد.

## المميزات
### 📿 المسبحة
- دائرة تسبيح كبيرة مع حلقة تقدّم، وأذكار جاهزة مع فضلها ومصدرها، وإضافة أذكار خاصة.
- الهدف: 33 / 99 / 100 / 500 / 1000 / بلا حد / رقم مخصّص — واسحب على بطاقة الذكر للتنقل بين الأذكار.
- تسبيح بعد الصلاة: 33 + 33 + 33 + التهليل مع انتقال تلقائي.
- **وضع التركيز**: شاشة سوداء كاملة، اضغط في أي مكان للتسبيح.
- **التسبيح بأزرار الصوت** (أندرويد).
- اهتزاز مع كل تسبيحة (3 مستويات)، ونبضة مميزة كل 10، واهتزاز خاص عند إكمال الهدف.

### ☀️ الأذكار
- أذكار الصباح، المساء، النوم، وبعد الصلاة — لكل ذكر عدّاد تكرار وفضله ومصدره.
- تتقدّم تلقائيًا للذكر التالي، وتتجدد كل يوم.

### 🕌 الصلاة
- مواقيت الصلاة بدون إنترنت (مكتبة adhan) عبر GPS أو اختيار مدينة، مع 12 طريقة حساب والمذهب الحنفي للعصر.
- عدّاد تنازلي للصلاة القادمة، تنبيه عند دخول الوقت، وتذكير بأذكار ما بعد الصلاة.
- **بوصلة القبلة** مع اهتزاز عند التوجه الصحيح، والمسافة إلى مكة.

### 🏆 إنجازاتي
- وِرد يومي مع حلقة تقدّم في أعلى الشاشة، وإحصائيات، ورسم لآخر 7 أيام، وسلسلة الأيام المتتالية.
- 20 إنجازًا (شارات)، ومشاركة الإنجاز، ونسخ احتياطي واستعادة.

### ⚙️ أخرى
- تذكير بأذكار الصباح والمساء، والجمعة، وتذكير دوري بالتسبيح. الضغط على الإشعار يفتح الشاشة المناسبة.
- التاريخ الهجري، 4 مظاهر، تكبير الخط، إبقاء الشاشة مضاءة، ويعمل بدون إنترنت.

## التثبيت على الموبايل
يعمل على **أندرويد 5.1 أو أحدث**.

1. نزّل الملف [`apk/sab7.apk`](apk/sab7.apk) على هاتفك.
2. افتحه واسمح بـ "التثبيت من مصادر غير معروفة" إذا طلب الهاتف ذلك.
3. عند تفعيل التذكيرات أو الإشعارات اسمح للتطبيق بإرسال الإشعارات.

## بناء التطبيق
```bash
npm install
npm run build        # نسخ ملفات الموقع إلى www/
npx cap sync android # تحديث مشروع أندرويد
cd android && ./gradlew assembleDebug
```
يتطلب Node 22 و JDK 21 و Android SDK (API 34).
يُبنى الـ APK تلقائيًا أيضًا عبر GitHub Actions عند الرفع على `main`.

يُوقَّع الـ APK بمفتاح ثابت (`android/app/sab7.keystore`، وهو مفتاح أندرويد التجريبي القياسي وليس سرًّا) حتى تُثبَّت كل نسخة جديدة كتحديث فوق السابقة دون فقدان البيانات.

## هيكل المشروع
| المسار | الوصف |
| --- | --- |
| `index.html`, `css/`, `js/` | واجهة التطبيق |
| `js/app.js` | التشغيل والتبويبات وزر الرجوع |
| `js/counter.js`, `js/adhkar.js`, `js/prayer.js`, `js/me.js`, `js/settings.js` | أقسام التطبيق |
| `js/data.js` | الأذكار والمدن وطرق الحساب والإنجازات |
| `js/platform.js` | الاهتزاز والإشعارات وأزرار الصوت (أندرويد + المتصفح) |
| `js/vendor/adhan.js` | حساب مواقيت الصلاة (MIT) |
| `android/` | مشروع أندرويد (Capacitor) |
| `scripts/` | نسخ الملفات وتوليد الأيقونات |
