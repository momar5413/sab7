# سُبحة 📿

سبحة إلكترونية (عدّاد تسبيح) تعمل على المتصفح وكتطبيق أندرويد.

## المميزات
- **دائرة تسبيح كبيرة** مع حلقة تقدّم، وتأثير لمس، وعدّاد للدورات.
- **أذكار جاهزة** مع فضل كل ذكر، وإمكانية **إضافة أذكار خاصة** بهدف مخصّص.
- **الهدف**: 33 / 99 / 100 / 500 / 1000 / بلا حد / رقم مخصّص.
- **وضع أذكار بعد الصلاة**: سبحان الله 33 ← الحمد لله 33 ← الله أكبر 33 ← التهليل، مع انتقال تلقائي.
- **اهتزاز** مع كل تسبيحة (خفيف / متوسط / قوي) واهتزاز مميّز عند إكمال الهدف.
- **إشعارات**: عند إكمال الهدف، وتذكير بأذكار الصباح والمساء، وتذكير يوم الجمعة بالصلاة على النبي ﷺ، وتذكير دوري بالتسبيح.
- **إحصائيات**: اليوم، آخر 7 أيام (رسم بياني)، المجموع، الأيام المتتالية، وأكثر الأذكار.
- **سهولة الاستخدام**: تراجع عن آخر تسبيحة، التسبيح بالضغط في أي مكان، إبقاء الشاشة مضاءة، تكبير الخط، 4 مظاهر (الصورة، زمردي، ليلي، فاتح)، زر الرجوع في أندرويد يغلق النوافذ، والسحب للأسفل لإغلاقها.
- كل البيانات محفوظة على الجهاز ويعمل بدون إنترنت.

## التثبيت على الموبايل
يعمل على **أندرويد 5.1 أو أحدث**.

1. نزّل الملف [`apk/sab7.apk`](apk/sab7.apk) على هاتفك.
2. افتحه واسمح بـ "التثبيت من مصادر غير معروفة" إذا طلب الهاتف ذلك.
3. عند تفعيل التذكيرات أو الإشعارات اسمح للتطبيق بإرسال الإشعارات.

## بناء التطبيق
```bash
npm install
npm run build        # نسخ ملفات الموقع إلى www/
npx cap sync android # تحديث مشروع أندرويد
cd android && ./gradlew assembleDebug
```
يتطلب Node 22 و JDK 21 و Android SDK (API 34).
يُبنى الـ APK تلقائيًا أيضًا عبر GitHub Actions عند الرفع على `main`.

## هيكل المشروع
| المسار | الوصف |
| --- | --- |
| `index.html`, `css/`, `js/` | واجهة التطبيق |
| `js/platform.js` | الاهتزاز والإشعارات وإبقاء الشاشة (أندرويد + المتصفح) |
| `android/` | مشروع أندرويد (Capacitor) |
| `scripts/` | نسخ الملفات وتوليد الأيقونات |
